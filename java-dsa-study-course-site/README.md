# Java + DSA Study Course Site

Production-style learning platform for the Apna College Java + DSA playlist:

```text
https://www.youtube.com/playlist?list=PLfqMhTWNBTe3LtFWcvwpqTkUSlB32kJop
```

The site turns the playlist into a structured placement-prep product with learner workspace, course player, theory, practice bank, progress analytics, cohort operations, assessments, and admin controls.

## Features

- Java + DSA module roadmap
- Searchable lesson/topic list
- Module-specific lesson player links that open the relevant course segment
- Module completion tracking in UI state
- Theory notes for every module
- In-depth concept hyperlinks for every explained topic
- Java implementation notes and common mistakes
- Linked practice-question bank for every module
- Lesson-level question links so learners can jump from theory to practice
- Practice queue for each module
- Learner dashboard with active tasks and progress health
- Practice workspace with module-level and full-course question banks
- Analytics view for mastery and question progress
- Admin view for cohorts, assessments, quality signals, and production controls
- Weekly study loop
- Links to the course playlist, Apna College channel, Java docs, and practice platform
- Responsive React + TypeScript implementation

## Run Locally

```bash
npm install
npm run dev
```

Open:

```text
http://127.0.0.1:5345
```

## Build

```bash
npm run build
```

## Notes

The playlist page itself may not expose full public video metadata to every automated environment. This site is based on public references identifying the playlist as Apna College's Java + DSA course and organizes the curriculum into a practical study plan with direct practice links.
