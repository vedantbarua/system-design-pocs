# Java + DSA Study Course Site

Study companion website for the Apna College Java + DSA playlist:

```text
https://www.youtube.com/playlist?list=PLfqMhTWNBTe3LtFWcvwpqTkUSlB32kJop
```

The site turns the playlist into a structured placement-prep roadmap with modules, daily rhythm, practice checkpoints, revision prompts, and progress tracking.

## Features

- Java + DSA module roadmap
- Searchable lesson/topic list
- Module completion tracking in UI state
- Theory notes for every module
- Java implementation notes and common mistakes
- Linked practice-question bank for every module
- Practice queue for each module
- Weekly study loop
- Links to the course playlist, Apna College channel, Java docs, and practice platform
- Responsive React + TypeScript implementation

## Run Locally

```bash
npm install
npm run dev
```

Open:

```text
http://127.0.0.1:5345
```

## Build

```bash
npm run build
```

## Notes

The playlist page itself may not expose full public video metadata to every automated environment. This site is based on public references identifying the playlist as Apna College's Java + DSA course and organizes the curriculum into a practical study plan with direct practice links.
